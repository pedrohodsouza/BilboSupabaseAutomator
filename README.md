# 🧙‍♂️ Bilbo — Supabase Edge Function Automator

Bilbo is a visual Node.js tool that automates migrating **Supabase Edge Functions** between projects.
It provides a simple and clean web interface built with **Express + Socket.io** for real-time execution feedback.

---

## 🚀 Features
✅ Download Edge Functions from any Supabase project  
✅ Transfer them seamlessly to another project  
✅ Real-time logs with terminal-style UI  
✅ Runs locally — no Supabase secrets stored  

---

## 🛠️ Installation

```bash
git clone https://github.com/pedrohodsouza/BilboSupabaseAutomator.git
cd BilboSupabaseAutomator
npm install
npm start
````

Then open [http://localhost:3000](http://localhost:3000) 🌐
